# AetherHV

**Windows Hypervisor Research & Memory Instrumentation Framework**

AetherHV is an experimental Windows hypervisor project focused on low-level system research, kernel development, Intel VT-x, EPT, and memory instrumentation.

The project explores communication between user mode, kernel mode, and VMX-root, alongside virtualization diagnostics and system-level analysis.

### Development Status

🚧 **Under Active Development**

This project is currently under development and is not considered stable or production-ready. Features, architecture, and functionality may change over time.
